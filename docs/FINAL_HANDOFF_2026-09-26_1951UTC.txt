- The original page is never edited. Every feature is a separate "layer" file added on top, which wraps the
  existing code and only reacts to new wording. Anything it does not recognise goes to the old code unchanged.
- After every change, 348 saved test questions (49 original questions, 207 older tiles, 12 breakout tiles, 16 setup
  tiles and 64 newer tiles) were asked again. Every answer had to match the saved one word for word before publishing.
  This held at every publish in this session. Any change that did show up was either an intended fix or was undone.

PART C. IDEAS: UNIQUE, USEFUL, HIGH IMPACT
----------------------------------------------------------------------------
1. Daily "what changed" digest: one answer each morning listing names that entered or left an uptrend, crossed
   cluster 1, flipped direction or started converging, for the whole market and for your saved lists.
2. Tracked lists with BUY / HOLD / SELL: save any answer as a list; each day the exit check and the adaptive builder
   propose changes, with a running equity curve against RSP.
3. Rotation playback: animate the market map and the sector scatter over the last 60 bars (a slider), to see money
   moving between sectors.
4. Risk budget builder: "10 names, max 12% volatility, beta under 1": weights solved so the portfolio meets the
   limits, with the risk contribution of each name shown.
5. Scenario check: "what if the market falls 5%": each list's expected move from its betas and correlations, and
   which names hedge it.
6. Regime banner: a single line on every page (trend / breadth / correlation regime) that changes the default
   weights of the smart builder automatically (defensive when breadth is weak and correlations are high).
7. Alerts on your tiles: pick a My tile and get a note when its answer changes (new names in or out).
8. Pairs monitor: the spread and z-score of your favourite pairs in one table, flagging those beyond 2.
9. Explain a pick: a "why this name" card combining its scorecard row, relative strength, convergence lenses and
   the nearest look-alikes, in plain English.
10. RealTest export of any smart portfolio as a ready-to-run test file, so ideas from Ask are backtested in one click.
